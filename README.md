#  Job Market Analysis (Web Scraping + EDA)

##  Problem Statement

The goal of this project is to analyze job market trends by collecting and examining job listings data to understand role demand and hiring patterns.

---

##  Dataset

* Job listings dataset scraped from a sample/fake jobs website (Real Python)
* Includes job titles, companies, and descriptions

---

##  Data Collection & Cleaning

* Scraped job data using Python
* Cleaned and structured the dataset
* Removed inconsistencies and duplicates

---

##  Exploratory Data Analysis

* Counted frequency of job roles
* Analyzed distribution of job titles
* Identified common patterns across listings

---

##  Key Insights

* Only a small percentage of job listings explicitly mention Python
* Developer-related roles appear most frequently
* Most companies appear only once in the dataset
* Job titles vary widely across industries

---

##  Tools Used

* Python
* Pandas
* Matplotlib
* Web Scraping
